取引先から「うちの取引先にはセキュリティの質問票を出してもらっています」と言われて、手が止まったことはないでしょうか。専任の情シスがいない会社では、1人の担当者が、通常の仕事の合間に答えを探すことになります。

この記事は、私が中小企業向けの情報を調べて整理したものです。前半は、IPA（情報処理推進機構）の自己宣言制度「SECURITY ACTION」の二つ星を取る手順、後半は質問票に答えるときの考え方です。IPAの公式ページで確認できたことだけを書き、確認できなかったことは「確認できなかった」と書きます。私は法律や認証の専門家ではないので、契約や法的な判断には触れません。

## SECURITY ACTION とは

IPAが運営する、中小企業が自分で「情報セキュリティ対策に取り組みます」と宣言する制度です。「一つ星」と「二つ星」があります。IPAのページには「一つ星でスタート！ステップアップで二つ星！」とあります。

ここで大事なのは、これが「審査に合格すると与えられる認証」ではなく、自己宣言だという点です。IPAの申込方法のページでも、「認定を受けました」「取得しました」という表現は不適切で、「一つ星（二つ星）を宣言しました」のように書くよう案内されています。取引先や自社サイトで使うときも、この言い方に合わせると安全です。

## 一つ星：6か条に取り組むと宣言する

一つ星は、「情報セキュリティ6か条」に今後取り組むことを宣言するものです。対策を実施する前でも申し込めるとされています。2026年10月30日時点のIPAの一つ星のページにある見出しは次の6つです。

1. OSやソフトウェアは常に最新の状態にしよう
2. ウイルス対策ソフトを導入しよう
3. パスワードを強化しよう
4. 共有設定を見直そう
5. バックアップを取ろう
6. 脅威や攻撃の手口を知ろう

昔の資料や記事には「5か条」と書かれているものがあります。私が確認した一つ星のページは6か条でした。古い記事を見ているときは、IPAの最新のページと見比べてください。

## 二つ星：自社診断と基本方針の公開

二つ星の要件は、IPAのページによると次の2つを行ったうえで宣言することです。

- 「5分でできる！情報セキュリティ自社診断」を実施する
- 「情報セキュリティ基本方針」を策定し、外部に公開する

### 自社診断（25項目）

25個の診断項目に答えて、自社の対策状況を把握するものです。PDF（IPAのページでは全8ページ）で配布されています。申込のときに診断の点数を入力します。

なお、診断ツールの入口は変更されることがあります。古い解説記事のリンクではなく、IPAの二つ星のページから入るのが確実です。配点や判定の区分は、確認できた範囲では公式PDFを直接見るのが正確でした。ここでは書きません。

診断の結果が悪くても、それで宣言できなくなるという趣旨のことは、私が確認したページには書かれていませんでした。ただ、点数は取引先に見せる可能性のある数字です。自分の会社の現状を測る物差しとして使うのが現実的です。

### 情報セキュリティ基本方針

「会社として、情報セキュリティにこう取り組む」という方針書です。IPAは、「中小企業の情報セキュリティ対策ガイドライン」の付録2にあるWord形式の雛形を案内しています（1ページ）。自社の事情に合わせて書き換えるだけで作れるとされています。独自に作ってもかまいません。

書くときのコツは、実際にやっていることだけを書くことです。立派な文章にして、実際はやっていない、というのが一番困ります。後で質問票に答えるときに、この方針と食い違いが出るからです。

### 公開の方法

基本方針の外部公開は、申込時に次のいずれかを選びます。

- 自社ウェブサイトへの掲載
- 会社案内やパンフレットへの掲載
- その他の方法

自社サイトを持っているなら、1ページ作って載せるのが一番簡単です。

## 申込の手順

IPAの「自己宣言の申込方法」のページで確認できた内容です。2026年4月1日に申込方法が変わっており、「SECURITY ACTION管理システム」から申し込みます。

1. 取組目標（一つ星か二つ星）を決める
2. GビズIDを取得する（取得済みなら次へ）
3. 申込フォームに入力する（個人情報の取扱いとロゴマーク使用規約への同意、事業者情報、取り組み内容）
4. 申込完了メールで、自己宣言IDとロゴマークの使い方を受け取る
5. ロゴマークをダウンロードする（任意）

注意点が3つあります。

- 2026年4月1日から、申込みにはGビズIDプライムまたはメンバーのアカウントが必須です。GビズIDは取得に日数がかかることがあるので、一番最初に動くのがおすすめです。IPAのページには、GビズIDの取得からロゴマーク使用までは最短1日で可能とありますが、システムの保守などで使えない期間もあるため、余裕を持つよう案内されています。
- 一つ星と二つ星の同時申込や、両方のロゴの同時使用はできません。
- 費用は、私が確認したページに記載がありませんでした。申込前にIPAの案内で確認してください。

## 質問票に答えるときの考え方

ここからは、制度の公式な決まりではなく、私が整理した実務の考え方です。取引先ごとに質問票の形は違い、IPAが「この質問票を使う」と決めているわけではありません。

### 1. まず「事実の一覧」を1つ作る

質問票は会社ごとに表現が違いますが、聞いている中身は似ています。更新（パッチ）、ウイルス対策、パスワードと多要素認証、バックアップ、持ち出しの管理、事故のときの連絡先、といったあたりです。

そこで、質問が来てから探すのではなく、自社の事実を1枚にまとめておきます。

- 誰が情報セキュリティの担当か
- 端末とサーバーの台数と、更新の方法
- ウイルス対策ソフトの有無
- 主要なサービス（メール・クラウド）の多要素認証の有無
- バックアップの対象・頻度・元に戻せるか試した日
- 事故が起きたときの連絡先と手順

この1枚が、一つ星の6か条と二つ星の自社診断の準備にもそのまま使えます。

### 2. 「やっている」と「やる予定」を分けて書く

一番やってはいけないのは、できていないことを「できている」と答えることです。後で事故が起きたとき、答えた内容が問われる可能性があります。選択肢に「一部実施」や「計画中」があればそれを選び、備考に「いつまでに何をするか」を書くほうが、取引先にも誠実に伝わります。

一つ星が「今後取り組む」宣言である点とも一致します。できていない所があること自体は、問題ではありません。隠すより、直す計画を見せるほうがずっと良いです。

### 3. SECURITY ACTION は「根拠の一つ」として添える

二つ星を宣言していれば、質問票の「セキュリティ方針があるか」「自己診断をしているか」の欄に、基本方針の公開先と自己宣言IDを答えとして書けます。ただし、取引先が二つ星を質問票の代わりとして認めるかどうかは、取引先ごとに違います。私は一律には言えません。「宣言はしています」と添えたうえで、聞かれた項目には個別に答えるのが無難です。

### 4. 答えた内容は控えを残す

誰が、いつ、どの内容で答えたかを保存します。次の取引先から似た質問が来たとき、使い回せます。ただし、使い回すときも「今も本当か」を必ず確認します。1年前の「更新している」が今も正しいとは限りません。

### 5. 法的に判断が要る項目は専門家へ

契約書の秘密保持や損害賠償、個人情報保護法に関わる質問、事故時の責任範囲などは、私は判断できません。弁護士・社会保険労務士・情報処理安全確保支援士など、その分野の専門家に相談してください。

## 最初の1週間でやること

| 日 | やること |
|---|---|
| 1日目 | GビズIDプライムを申請する |
| 2〜3日目 | 25項目の自社診断を、事実の一覧を見ながら埋める |
| 4〜5日目 | 基本方針を雛形から書き、自社サイトに載せる |
| 6〜7日目 | 申込フォームに入力して、一つ星または二つ星を宣言する |

GビズIDが届くまでの間に、診断と基本方針は進められます。

## まとめ

- SECURITY ACTIONは認証ではなく自己宣言。言い方は「宣言しました」
- 二つ星は、25項目の自社診断と、基本方針の外部公開が要件
- 2026年4月から申込にはGビズIDが必須。最初に取る
- 質問票は、事実の一覧を1枚作っておけば、ほとんど使い回せる
- できていない所は、隠さず「計画」を書く
